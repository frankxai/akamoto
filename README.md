# Akamoto

The forgotten Prophecies of Darkness and Light. A work of fiction in the world of Arcanea, published at akamoto.io.

Next.js 16, TypeScript, pnpm. Waitlist runs on the estate's shared `demand-capture` package (vendored in `lib/demand-capture`, product id `akamoto-prophecies`). Needs `KV_REST_API_URL`, `KV_REST_API_TOKEN`, `RESEND_API_KEY`, `RESEND_AUDIENCE_ID` to take names; without them the Register renders and reports that it is not taking names yet.

```
pnpm install
pnpm dev
```
